### Day build

**You own the queue and the verdicts. Builders own their tickets. Nothing merges, and every verified PR waits for the Evening session.**

This starts when Alex answers "Go" to the morning brief. Conventions, the claim rule and the two-layer contract are in `linear.md`. The team is whichever team owns the project, and states are mapped by type: Ready is `unstarted`, In Progress is `started`, and In QA is the state Linear calls In Review. Run **Autopilot-stack** over the queue below, with its queue taken from the Linear project instead of GitHub. The overrides in step 3 go into every builder's kickoff. `worker.md` makes them the whole bar: "The bar in your kickoff is the whole bar."

1. **Create the tickets.** Run **to-tickets** in create mode with the approved list from the brief. Report the identifiers and blocking edges.
2. **Build the queue.** The queue is every Ready ticket in the project that is not blocked, not In Progress and has no assignee. Use `list_issues`. If Linear's blocked-by data looks stale, trust the PR state and track blocking in `keel-store`, per `linear.md`. Add a ticket to the queue when its last blocker reaches In QA.
3. **Dispatch one builder per ticket.** Claim the ticket first: set In Progress and the assignee. Then spawn one `keel:ponytail` with `isolation: "worktree"`. Each kickoff opens with `Read <skills dir>/lead/worker.md before anything else.`, links the ticket and its `Spec:` document, and carries the two-layer contract from `linear.md`: the file paths, which you find by reading the code now, the base branch, and the stop at verified. It states these overrides in so many words:
   - **Merge policy.** Open the PR ready per `playbooks/opening-a-pr.md`, babysit it to green, and stop. Never merge.
   - **Discovered work.** Report anything found outside the ticket to the lead in your final report. Never open a PR for it and never fix it. This overrides `autonomous-run.md` step 4 and the "fix it in the next round" line in **principle-never-block-on-the-human**.
   - **Fix cap.** Take at most two fix rounds on review findings. After the second, add the label `needs-alex`, leave the ticket In Progress, comment what failed, and stop. This overrides "A plateau is not a stop." If the label is missing, leave the ticket In Progress and comment that it needs Alex.
   - **Linear.** Writes to this project (claim, state moves, comments) count as part of the run, so `worker.md`'s stop before a message to someone outside the run does not apply to them.
   - **Scope.** The ticket's pass predicates and out-of-scope list are the whole job.
4. **Collect discoveries.** As each builder reports, append its discovered items to the `Discovered work: <project>` document, with the ticket, the finding and the evidence. You alone write it. Create it if it does not exist.
5. **Review once.** When every started builder has reported a PR or stopped, spawn one `keel:critic` pass over all of the day's PRs together, not one swarm per PR. Give it the correctness lens, with each ticket's pass predicates in the brief next to its PR, and ask it to run each predicate on the PR's head. Add a second critic only where a PR moves a security or authority boundary. A finding goes to a fresh `keel:ponytail` on the same branch as a fix round, counted against the ticket's cap. Re-review only the PRs whose patch changed.
6. **Verify and move.** A PR is verified when its predicates pass at its current head and its CI is green. Move a verified PR's ticket to In QA and post the verdict, `PASS` or `PASS+NOTES`, on the PR. A ticket at its cap carries `needs-alex`, as its builder's kickoff said.
7. **Stop** when no unblocked, unclaimed Ready ticket is left and every started PR is verified or handed back, or at 7 PM, whichever comes first. At 7 PM, let a builder that is mid-fix finish its commit, move nothing else, and list its ticket as unfinished. Never merge, and never promote a Backlog ticket.

**Reply:** each ticket with its PR, verdict and state, the tickets on `needs-alex`, the items appended to the discovered-work document, and what is unfinished. Per **ketchup**, this is the list Alex works from at 7 PM.
